# Wyrmbound v3
Original idle dragon RPG, 2.5D field with full auto-quest loop. Single-file HTML5 build: `python3 build.py 3` -> site/.
Sources: game.js (systems), field.js (field world/auto), head.html (shell), build.py, gfx3.js (v3 renderer: tiled terrain, props, hit flash, VFX). Art embedded as webp.
